# Raspberry №1, №2, №3

Основная инструкция: [START_HERE.md](START_HERE.md).

- №1: lab01_rgb.py — RGB и три кнопки.
- №2: lab02_camera.py — камера Picamera2 и серво.
- №2, только старый camera stack: lab02_camera_legacy.py.
- №3: lab03_weather.py — BME280, влажность, давление в мм рт. ст., LED.

Все программы запускаются на Raspberry, не на Windows. Физические номера BOARD.
HA и веб-сервера в комплекте нет. Аппаратная проверка выполняется в аудитории.
